## 📋 Общая информация

**Название проекта:** MANI — сервис онлайн-записи для бьюти-студии "Ноготочки"

**Описание:** Веб-приложение для онлайн-записи клиентов к мастерам маникюра с возможностью управления расписанием, услугами и записями через административную панель.

**Технологический стек:**
- Backend: Node.js 24.x (встроенный `node:sqlite`)
- Database: SQLite3 с триггерами и транзакциями
- Frontend: Vanilla JavaScript, HTML5, CSS3
- Авторизация: Local (email/password) + OAuth через Яндекс ID

## 🗄️ База данных

**Файл:** `.data/mani.sqlite` (SQLite3)

### Схема таблиц:

- `users` — пользователи (клиенты, мастера, администраторы)
- `sessions` — активные сессии (SHA-256 хеши токенов)
- `masters` — мастера с привязкой к пользователям
- `services` — доступные услуги
- `master_services` — связь мастеров и услуг
- `schedules` — еженедельное расписание мастеров
- `time_blocks` — блокировки времени (обеды, выходные)
- `appointments` — записи клиентов
- `appointment_services` — услуги в конкретной записи
- `holds` — временные удержания слотов (5 минут)

### Защита от конфликтов:

**Триггер `prevent_overlap`** (lines 219-234 в `001-schema.sql`):
```sql
CREATE TRIGGER prevent_overlap BEFORE INSERT ON appointments
BEGIN
  SELECT CASE
    WHEN EXISTS (
      SELECT 1 FROM appointments existing
      WHERE existing.master_id = NEW.master_id
        AND existing.status = 'booked'
        AND NEW.intentional_overlap = 0
        AND NOT (NEW.ends_at <= existing.starts_at OR NEW.starts_at >= existing.ends_at)
    )
    THEN RAISE(ABORT, 'OVERLAP')
  END;
END;
```

Триггер срабатывает **до** вставки записи в транзакции и блокирует сохранение при пересечении времени.
