ВЫПОЛНЕННЫЕ ТРЕБОВАНИЯ:

✅ Расписание мастеров: вторник-суббота, 10:00-20:00 (МСК)
✅ Обеденный перерыв: 14:00-15:00 (автоматически блокируется)
✅ Разграничение доступа: клиент/администратор
✅ Защита от двойной записи (триггер БД)
✅ Отмена записи клиентом
✅ Управление записями администратором (отмена, завершение)
✅ Личный кабинет клиента с визуальными карточками
✅ Административная панель с управлением
✅ Авторизация: email/пароль + OAuth Яндекс ID
✅ Безопасность: scrypt-хеширование, SHA-256 токены, защита от SQL-injection

СОДЕРЖАНИЕ ВИДЕО-СКРИНКАСТА (4-6 мин):

1. Сценарий клиента (1.5-2 мин):
   - Вход клиента (client@mani.local)
   - Создание записи (выбор услуги, мастера, времени)
   - Просмотр в личном кабинете
   - Отмена записи

2. Сценарий администратора (1.5-2 мин):
   - Вход админа (admin@mani.local)
   - Просмотр всех записей в /admin
   - Отмена записи от имени салона
   - Завершение записи

3. Разграничение доступа (30 сек):
   - Клиент пытается открыть /admin
   - Показана ошибка 403

4. Расписание (30 сек):
   - Календарь без понедельника и воскресенья
   - Отсутствие слотов 14:00-15:00 (обед)

ТЕХНОЛОГИЧЕСКИЙ СТЕК:

- Backend: Node.js 24.x (встроенный node:sqlite)
- Database: SQLite3 с триггерами и транзакциями
- Frontend: Vanilla JavaScript, HTML5, CSS3
- Авторизация: Local + OAuth (Яндекс ID)

ЛОКАЛЬНЫЙ ЗАПУСК (для проверки):

1. git clone https://github.com/2406438-oss/Mani.git
2. cd Mani
3. npm run db:migrate
4. npm run db:seed
5. npm start
6. Открыть http://localhost:3000/

Тестовые аккаунты:
- Клиент: client@mani.local / ClientDemo!24
- Админ: admin@mani.local / AdminDemo!24
